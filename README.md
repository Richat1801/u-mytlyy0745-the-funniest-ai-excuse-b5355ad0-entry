A deterministic Node program that keeps a small bank of original one-line excuses an AI agent gives after failing a task, scores each on the judge's axes (agent's own voice, funny turn, freshness, vivid detail), and writes only the winner to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
